# 📸 Screenshooter

A lightweight and elegant native macOS menu bar application for screenshot capturing and management, built with Swift & SwiftUI.

## ⚡ Features

- **Global Hotkey** — Customizable system-wide shortcut via Carbon API.
- **Area Capture** — Interactive crosshair drag-and-select overlay.
- **Gallery Popover** — Premium dark interface with capture history & quick actions.
- **Clipboard & Finder** — Auto-copy to clipboard and reveal in Finder.

## 🚀 Quick Start

### Build & Run
```bash
make
```
Run `Screenshooter.app` from the project root.
